**DupeSweeper** एक आधुनिक, अत्यधिक तीव्र और 100% ऑफ़लाइन डेस्कटॉप एप्लिकेशन है जो **Windows, Linux और macOS** का समर्थन करता है। यह एक ही हल्के ऐप में दो शक्तिशाली सुविधाएँ प्रदान करता है:
1. **🔍 डुप्लिकेट फ़ाइल फाइंडर:** **BLAKE3** क्रिप्टोग्राफ़िक सामग्री हैशिंग का उपयोग करके सटीक समान फ़ाइलों का पता लगाता है।
2. **🧹 सिस्टम जंक क्लीनर:** अस्थायी फ़ाइलों, ब्राउज़र कैश, थंबनेल डेटाबेस, पुराने लॉग्स और डाउनलोड फ़ोल्डर में अप्रयुक्त इंस्टॉलर्स को सुरक्षित रूप से साफ़ करता है।

यह एप्लिकेशन **5 MB से कम आकार की सिंगल स्टैंडअलोन बाइनरी** में संकलित होता है, जिसमें किसी बाहरी रनटाइम की आवश्यकता नहीं होती, कोई विज्ञापन नहीं होता और **क्लाउड पर 0 बाइट डेटा भेजा जाता है**।

### 🛡️ Windows SmartScreen और सुरक्षा संबंधी जानकारी

पहली बार `DupeSweeper-Setup.exe` या `DupeSweeper.exe` चलाने पर Windows Defender / SmartScreen एक नीली चेतावनी स्क्रीन दिखा सकता है:
> **"Windows protected your PC"**  
> *Microsoft Defender SmartScreen prevented an unrecognized app from starting.*

#### 🤔 यह चेतावनी क्यों दिखाई देती है?
1. **मुफ्त ओपन-सोर्स सॉफ्टवेयर:** DupeSweeper 100% मुफ्त और ओपन-सोर्स है। Microsoft SmartScreen उन नए `.exe` ऐप्स को चेतावनी दिखाता है जिनके पास महंगा कमर्शियल कोड-साइनिंग सर्टिफिकेट (प्रति वर्ष \$300–\$500) नहीं होता।
2. **नई रिलीज़ प्रतिष्ठा:** Microsoft सर्वर पर नए संस्करण को प्रतिष्ठा बनाने में कुछ समय और डाउनलोड की आवश्यकता होती है।

#### 🚀 ऐप को कैसे शुरू करें (केवल पहली बार):
1. SmartScreen विंडो पर **"More info"** लिंक पर क्लिक करें।
2. नीचे दाएं कोने में दिखाई देने वाले **"Run anyway"** बटन पर क्लिक करें।
3. DupeSweeper तुरंत खुल जाएगा!

> 🔒 **100% सुरक्षा एवं गोपनीयता गारंटी:**
> - **100% ऑफ़लाइन (जीरो टेलीमेट्री):** ऐप इंटरनेट से कनेक्ट नहीं होता और कोई डेटा नहीं भेजता।
> - **एडमिनिस्ट्रेटर अधिकारों की आवश्यकता नहीं:** साधारण उपयोगकर्ता अनुमति (`asInvoker`) पर सुरक्षित रूप से चलता है।
> - **पारदर्शी एवं ओपन-सोर्स:** पूरा कोड GitHub पर खुला है और GitHub Actions CI द्वारा सत्यापित है।

## ⚡ उच्च-प्रदर्शन आर्किटेक्चर

- **बैकग्राउंड डिलीशन वर्कर (`DeleteWorker`):** फ़ाइल विलोपन बैकग्राउंड में चलता है, जिससे UI कभी हैंग या फ़्रीज़ नहीं होता।
- **वर्चुअलाइज्ड व्यूपोर्ट (`show_rows`):** केवल स्क्रीन पर दिखाई देने वाली पंक्तियों को रेंडर करता है। **100,000+ फ़ाइलों** पर भी 60 FPS स्मूथ स्क्रॉलिंग।
- **एसिंक्रोनस थंबनेल वर्कर:** इमेज थंबनेल बैकग्राउंड में लोड होते हैं बिना मुख्य इंटरफ़ेस को धीमा किए।
